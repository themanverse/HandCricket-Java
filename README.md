# HandCricket-Java

A console-based Hand Cricket game built in Java.

This repository contains two versions of the project, showing the evolution of my programming journey from raw logic-focused coding in class 10 to a more structured and modular approach.

---

# Versions

## Legacy Version
The original version created during class 10.

Features:
- Odd/Even toss system
- Batting/Bowling selection
- Full innings gameplay
- Score tracking
- Target chasing
- Match result system
- Basic input validation

Characteristics:
- Procedural programming
- Logic-focused implementation
- Minimal modularity
- Experimental design approach

---

## Remastered Version
A redesigned and restructured version built later in class 12th using improved programming practices.

Features:
- Improved input validation
- Modular method-based architecture
- Multi-match scoreboard
- Replay functionality
- Cleaner gameplay flow
- Better user interaction
- Reusable innings systems

Concepts Used:
- Methods
- Loops
- Conditional Logic
- Random class
- Scanner class
- Input validation
- State management

---

# Purpose of This Repository

This project reflects my growth as a programmer:
- from writing everything inside `main()`
- to building reusable and structured systems.

The repository preserves both versions to showcase the learning and evolution process.
